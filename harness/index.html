GifOS test harness

Runs atomic checks against the live site https://gifos.app. People do not have to watch. An agent can press Run, or call gifosHarness.run() from the console on this page.

Drive it from a real browser

Open this page, or inject harness/suite.js into a tab that is already on gifos.app. Injection adds DOM checks for the Home Screen or the meeting page you are on. The fetch checks run either way.

await page.goto('https://gifos.app/run');
await page.addScriptTag({ path: 'harness/suite.js' });
const report = await page.evaluate(() => gifosHarness.run());
// report.summary is { total, pass, fail, blocked }
// report.tests is one row per check: { id, suite, name, ok, detail }

A meeting debug log for a person is not this page. In the meeting, open More → Settings and use the debug switch and the download in that dialog. export-meet-debug.js is an optional console helper for an agent, not the human path.
